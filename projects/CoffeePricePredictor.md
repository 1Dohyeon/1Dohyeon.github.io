# 커피 생두 가격 예측 시스템

## 프로젝트 개요

- **개발 기간**: 2025.03 ~ 2025.06
- **기술 스택**: Python, PyTorch, scikit-learn, FastAPI, React, Docker
- **프로젝트 유형**: 6인 프로젝트 (대학 캡스톤)
- **맡은 역할**: 데이터 수집·가공 파이프라인, 모델 학습 비교 실험, 예측 서버(FastAPI)와 UI

> [데이터 가공 Repository](https://github.com/MJU-Capstone-2025/data-prep) · [서버 Repository](https://github.com/MJU-Capstone-2025/model-server) · [UI Repository](https://github.com/MJU-Capstone-2025/web-ui) · [팀 최종 모델](https://github.com/MJU-Capstone-2025/Coffee_Price_Prediction)

## 배경

기후변화와 경제 불확실성으로 커피 시장의 가격 변동성이 커지면서, 원두 구매 업체가 구매 시점을 정하기 어려워지고 있습니다. 커피 재배 지역의 기후 데이터, 거시 경제 지표, 뉴스 기사를 함께 분석해 단기 커피 선물 가격을 예측하는 시스템을 목표로 했습니다.

## 내가 한 일

### 1. 데이터 수집·가공 파이프라인

브라질, 콜롬비아, 에티오피아 3개국 9개 산지의 NASA 기후 데이터(2015 ~ 2025)와 yfinance 기반 시장 데이터(Coffee C 선물, WTI 유가, 산지 통화 환율)를 수집하고, 수집부터 최종 학습 데이터까지 한 번에 만드는 파이프라인을 작성했습니다.

- **1차 가공**: 결측치를 처리하고, 커피 가격과 일간 수익률을 타깃으로 병합했습니다.
- **2차 가공**: 기후 변수 18개를 상관이 높은 그룹(기온, 풍속, 일사량 등)별로 묶어 대표 변수 7개로 줄였습니다.
- **파생 변수**: 산지별 수확 시기(`season_tag`), 다음 수확까지 남은 일수, 기온·풍속·일사량·강수량의 1 ~ 6개월 전 값(lag feature)을 만들었습니다.
- 데이터와 피처 설명 문서, 상관관계 시각화를 함께 남겨 팀원이 같은 데이터를 바로 쓸 수 있게 했습니다.

### 2. 모델 학습 비교

**Random Forest로 예측 가능성 확인**

2015 ~ 2024년 데이터로 학습해 2025년 1 ~ 4월을 예측했습니다. 가격을 직접 예측하면 2023년 이후 급등한 가격대에 대응하지 못하고 과거의 낮은 가격대로 예측하는 문제가 있어, **예측 대상을 가격에서 일간 수익률로 바꿨습니다.** 수치형 피처 스케일링 유무도 비교해, 스케일링을 하면 변화폭을 보수적으로 예측하고 빼면 과감해지지만 정확도는 제한적이라는 것을 확인했습니다. 단기(2주) 추세는 어느 정도 맞았지만 약 3개월이 예측 한계였고, 시계열 모델로 넘어가는 근거가 됐습니다.

**LSTM + Attention 실험**

- 손실 함수로 MSE와 Huber Loss를 비교하고, 학습 손실이 5 에폭 이후 크게 진동해 에폭을 5로 고정했습니다.
- 기본 모델과 잔차 기반 모델의 예측 결과를 비교했습니다.
- 테스트 구간 전체를 한 번에 예측하는 방식과, 50일 입력으로 14일을 예측하고 7일씩 옮기는 슬라이딩 윈도우 방식을 비교했습니다. 슬라이딩 윈도우가 단기 추세를 더 잘 따라갔습니다.
- 슬라이딩 윈도우의 한계도 분석했습니다. 연속된 윈도우의 입력이 약 86% 겹쳐 예측 패턴이 반복되는 문제가 있어, 4주 예측에서는 입력 기간과 예측 구간을 늘리는 방안을 제시했습니다.
- 실제 시장 휴장일을 반영해 예측 날짜를 보정했습니다.

### 3. 예측 서버와 UI

- 팀 최종 모델(LSTM-Entmax)을 모듈로 나눠 FastAPI 서버에 통합하고, 7일·14일 예측 결과와 모델 정보를 API로 제공했습니다.
- 팀원이 만든 뉴스 감성 분석 결과를 조회하는 API를 추가했습니다.
- React로 예측 결과와 뉴스 목록을 보여 주는 UI를 만들고, 서버와 UI를 Docker로 구성했습니다.
- 같은 모델로 예측 구간을 56일, 1년으로 늘려 장기 예측 가능성을 실험했고, 흐름은 따라가지만 급격한 변화는 늦게 반영한다는 점을 확인했습니다.

## 팀 결과

최종 예측 모델(Attention-LSTM + Entmax)과 7일·14일 예측을 함께 쓰는 구매 시점 전략은 팀원이 설계하고 검증했습니다. 7일 모델 RMSE 9.14, 14일 모델 RMSE 12.91의 성능을 냈고, 뉴스 기사 감성 분석은 FinBERT로 별도 모델을 만들어 참고 지표로 활용했습니다.

## 현재 한계

애초 목표는 실시간 데이터를 수집해 당일 기준 미래 가격을 예측하는 것이었습니다. 그러나 거시 경제 지표 대부분이 유료 API이거나 월별로 발표돼 실시간 수집에 제약이 있었습니다. 그래서 확보한 과거 데이터로 학습과 테스트를 진행했고, 실시간 수집이 가능해지면 같은 서버 구조로 당일 기준 예측을 할 수 있도록 설계해 두었습니다.
